# 圆心检测 — VS 2022 / C++17
检测样例图中 **4 个完整的小圆孔**。

## 样例结果

图像为 818×614 像素，自动二值化阈值为 127。按圆心从上到下编号：

| 编号 | 圆心 x / px | 圆心 y / px | 半径 / px | 边缘拟合 RMS / px |
| --- | --- | --- | --- | --- |
| 1 | 459.751 | 148.018 | 43.154 | 1.300 |
| 2 | 467.115 | 339.735 | 23.936 | 0.383 |
| 3 | 584.117 | 490.633 | 40.791 | 0.669 |
| 4 | 768.237 | 544.557 | 23.696 | 0.426 |

## 方法

灰度化 → 3×3 中值滤波 → Otsu 深色前景二值化 → 3×3 闭运算 → 八邻域连通域 → 完整近圆区域筛选 → 提取边界 → 最小二乘圆拟合。

筛选时去除距图边不超过 2 像素的区域；面积范围为 `max(20, 图像面积×0.0006)` 至图像面积的 5%；宽高比 0.75～1.33；二阶矩主轴比不超过 1.35；面积/边界框面积 0.65～0.90。背景阴影、文字、边框和被截断的大孔因此不会作为目标。

在候选区域中，以有四邻域背景的前景像素作为边界。设区域质心为 `(x0,y0)`、边界相对坐标为 `(u,v)`，最小二乘求解：

`2u·a + 2v·b + c = u² + v²`

得到圆心 `(x0+a,y0+b)`、半径 `sqrt(c+a²+b²)`，再计算径向 RMS，并排除 RMS 超过 `max(1.5 px, 0.06×半径)` 的区域。这里的质心仅用于数值平移，最终圆心来自边界拟合，不直接用质心或矩形框中心代替。

此实现不使用霍夫变换，采用完整孔区域的边界圆拟合。对明显椭圆、强透视、粘连孔、缺口或复杂背景，当前规则可能漏检或误检。输出为图像像素坐标；若需机械平面上的物理坐标或尺寸，应另做镜头畸变、透视及尺度标定。
